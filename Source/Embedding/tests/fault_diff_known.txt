# Differences Scripts/macos_fault_diff.py knows about and does not fail on: case, check.
# Each is a limit of the translator that package D did not fix, at the fault only: running
# again gives x86's result in every case. See
# docs/macOS-embedding-interface.md, "Guest memory faults: what is exact".
#
# Every restartable-fault entry (read-modify-write flags, pop [m], leave, rep movs/stos,
# the 32-byte store, the call stack) is fixed: undo records and in-place rep loops.
#
# Flags at the fault are exact (KeepFlagsLive before every instruction that can fault);
# the dead-flags entries are gone. Entries apply to a case's flag-prelude variants too.
#
# Multi-part stores that can leave part of their data written before a fault (running
# again writes the same data, so the resumed result is right; only the memory seen at the
# fault differs from x86's):
ystore-cross-low-ro    at-fault   # 32-byte store whose LOWER page faults: the upper half is stored first
fxsave-cross-ro        at-fault   # fxsave across a page: written in parts (x86 too may leave it partly written)
rvw-fstp-tbyte-cross8-ro at-fault  # 80-bit x87 store across a page whose upper page faults: the lower 8 bytes are written first
rvw-fstp-tbyte-cross9-ro at-fault  # the same, 9 bytes below the page
