# Contributing

This is an independent macOS (Apple silicon) port of FEX, maintained separately from the
upstream FEX-Emu/FEX project.

- This port uses AI-assisted development. Upstream FEX does not accept AI-assisted
  contributions, so **do not submit anything from this repository upstream**.
- Open pull requests against this repository only.
- Changes are Mac only and must be tested on Apple silicon.
- If you want to contribute to FEX itself, do that at FEX-Emu/FEX, under their rules, with
  work that did not come from here.
